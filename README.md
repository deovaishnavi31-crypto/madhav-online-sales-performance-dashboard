# Madhav Online Sales Dashboard | Power BI

## Overview
Online Sales Performance Dashboard to track sales, profit, 
quantity and AOV across product categories and customer segments.

## Key Metrics
- Total Amount: 21K
- Total Profit: 3K
- Total Quantity: 328
- Average Order Value (AOV): 5.89K

## Features
- Quarterly filters (Qtr 1, 2, 3, 4)
- State-wise navigation filter
- Profit by Month (including losses)
- Quantity by Category
- Sales by Payment Mode
- Profit by Sub-Category
- Quantity by Customer Name

## Tools Used
- Power BI Desktop
- DAX
- Power Query (M-Query)
